# REALCITY — Asset Credits

## Protagonist base character

- Asset: Universal Base Characters — Superhero_Male_FullBody / textured Quaternius-derived night-striker.glb
- Original creator: Quaternius
- Original pack: https://quaternius.com/packs/universalbasecharacters.html
- Source mirror used for the preview loader: https://github.com/Seyamalam/blood-league-kickoff/blob/main/public/assets/vendor/quaternius/night-striker.glb
- License: CC0 1.0 Universal, as documented by the source project's asset ledger and Quaternius pack page.
- Runtime use: loaded asynchronously by src/main.ts. The game verifies a skinned mesh, texture/vertex color, and mapped left/right leg and arm bones before replacing the animated procedural fallback.
- Animation: when compatible named idle/walk/run clips are absent, REALCITY uses procedural bone locomotion. The current source mirror is external; a future asset pass should vendor a size-optimized copy locally and record its checksum.

## Original procedural assets

Road markings, facade texture, lighting gradients, building trim, and the procedural fallback human are generated by REALCITY source code. They do not require external image or texture downloads.
