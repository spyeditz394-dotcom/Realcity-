Imported models are from Kenney's Car Kit, released under CC0 1.0 Universal. The upstream repository copy includes the original `LICENSE.txt` from the downloaded archive.

- Official source: https://kenney.nl/assets/car-kit
- Pack download listing: https://kenney-assets.itch.io/car-kit
- License: CC0 1.0 Universal; the included upstream license text is authoritative.
- Upstream mirror used to transfer the binary files into this repository: T-Py-T/Carla_RL, commit 0ec96ff6cfd5a88a82545d34af1d069992bbc7b7, under `model-sim/demos/web/public/models/traffic/kenney-car-kit/`.
- Files included here: realcity-hatchback-sports.glb, realcity-taxi.glb, realcity-suv.glb, realcity-van.glb, realcity-truck.glb.
- REALCITY integration is responsible for scaling each visual mesh to the existing vehicle collision footprint; these are visual meshes, not physics definitions.

These are stylized game-ready vehicles, not photorealistic scans. No affiliation with any real vehicle manufacturer is implied.
